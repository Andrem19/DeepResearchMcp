# Deep Research Request Example

## Example: Using the deep_research tool

### Simple request

```
Use the deepresearch MCP tool to investigate this topic:

What is the Model Context Protocol (MCP) and how does Streamable HTTP transport work?

Return the report as Markdown and keep citations intact.
```

### With parameters

```
Use the deepresearch tool with:
- query: "What are the latest developments in Rust async programming?"
- depth: "deep"
- max_sources: 10
- recency_days: 90

Return the full report.
```

### Quick overview

```
Use the deepresearch tool with depth="quick" to get a brief overview of:
WebAssembly component model specification
```
